# Deatalos 1.5.0 正式版

## 1.5.0 的变化

- **一次提交更完整的回路。** 所有 MCP 客户端的绘图候选上限由 30 条命令提高到 120 条。一次候选内可以添加元件、连接油口并设置参数，在工作台一次确认，也可以一次撤销。
- **多回路任务逐项核对。** Agent 指南要求按用户指定的功能核对执行元件、必要连接和共用供回油，明确报告已完成和仍缺少的部分。候选待确认、已经应用、已做静态检查和已经仿真分别报告。
- **接线问题可以定位到端口。** 预览回执区分漏接的必接端口和允许闲置的端口。例如夹紧阀的 P 口缺少供油连接时，可以直接定位并修补。运行性能仍以实际仿真为准。
- **外部 AI 控制统一使用 hydraulic MCP。** 新工程随附 MCP 操作指南。已有文件夹工程在保存时更新软件提供的默认指南，并保留用户自定义说明。

MCP 服务可以直接用 Node.js 启动，无需另外安装 Electron 开发依赖。

## 从 1.4.1 升级

先保存工程并退出工作台，运行下方 Windows x64 离线安装包。如果此前使用 HydraulicTool.exe、PowerShell 或手动地址和令牌连接 AI，请在客户端改配本机 stdio MCP 服务 `hydraulic`。安装包自带服务入口，启动命令填写 Node.js 可执行文件，参数按以下顺序填写：

1. 安装目录下 `resources/app.asar.unpacked/dist/network-mcp.cjs` 的绝对路径
2. `--workspace`
3. 已存在的工程工作区的绝对路径
4. `--open-projects`

保存文件夹工程后，在工作台开启「允许 AI 操作」，再让客户端调用 `hydraulic_list_projects` 查找工程。仿真控制仍需单独授权。

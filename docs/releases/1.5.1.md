# Deatalos 1.5.1 正式版

适用于 Windows x64，可从 1.5.0 升级。

- 安装器登记工程、曲线和图框的打开方式。已打开的工作台可接收新的文件。
- 设置中可调整启动时的 AI 控制默认值，工具栏按钮可随时切换本次会话。工程中的 MCP 指南补充首次接入、任务导航和资料迁移说明。
- 画布新增四向和八向鼠标笔势，可拖动分配命令，调整内外环大小、比例锁和触发灵敏度。支持连续裁剪管线、撤销，以及在管线右键菜单中添加折点和恢复自动布线。
- 设置中可开启自动低压续算，运行中触发时会提示。改进了供压缓冲缸、节流支路和液控单向阀组合的仿真处理。
- 整理编辑、视图和帮助入口。右侧面板宽度可以单独复位。星球主题使用预制玻璃材质，保留圆形扩散动画。

升级前请保存工程并退出工作台。安装包未签名。

本版通过相对 1.5.0 的 19 组增量验收，并已从安装包解出工作台复验文件打开和主题切换。Windows x64 安装包为 117,456,675 字节。附件 SHA256SUMS.txt 可用于校验下载文件。

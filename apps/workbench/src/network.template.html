使用帮助

“视图 → 状态栏”可勾选右侧显示项目，支持全部显示、全部收起及恢复默认，并记住本机选择。原菜单窗口仍可打开同一面板，关闭后回到勾选的右侧位置；未应用输入保留。可拖动弹窗标题栏调整位置。

元件库与区域调整

元件库浮在画布内。按中文名称或类别搜索。“视图 → 元件库”右侧显示当前模式，点击该行切换阵列或滚动。 默认使用滚动版，卡片显示元件简图和名称；一次展开一个类别：滚轮、左右键或两侧箭头循环切换，点中央卡片添加，点侧卡片先选中；滚轮仅在卡片区域切换，不改变画布缩放。阵列使用同一套已确认简图，悬停可看全名；点击添加，或把元件拖到画布释放处放置；Esc或画布外释放取消。画布和导出继续使用工程符号。

元件库默认窄长，拖动四边或四角可拉宽、拉窄、拉长、缩短；右下角获焦后方向键可调宽高，Shift加速，尺寸和位置记在本机。拖动元件库标题移动；“−”最小化，再点可展开；“×”关闭。从“视图 → 元件库”切换并恢复。关闭库不会删除任何工程元件。小画布点击卡片后自动最小化库，方便查看；点标题“□”展开。标题获焦时方向键也可移动。

拖动画布与属性结果区之间的细分隔条连续调整区域；分隔条获焦后方向键可调宽，双击恢复默认。位置和区域尺寸仅保存在本机，不改工程参数或仿真结果。窄窗口从右上“属性与结果”打开面板，再点“×”收起。

画布左→右拖框（蓝色）完全包围元件以选择，右→左拖框（橙色）与线相交即选线；两种方向分别只选对应类型，Shift可追加同类选择。选线后Delete或“编辑→删除”批量删除。Esc取消手势/连接并清除选择。选中元件后空格顺时针旋转90°，多选绕各自中心；Ctrl+C/X复制/剪切元件、节点与内部连线，外部连线不带并提示。Ctrl+V在当前视区中心粘贴，连续粘贴偏移24绘图单位。文字输入框内保留原生快捷键；Enter仍可操作获焦阀位。滚轮缩放，中键平移；右下角“适合全图”或Home显示完整回路。主界面不显示缩放百分比。常用操作在菜单下方，低频操作在多级菜单，鼠标移到顶部菜单文字即展开，点击和键盘操作也保留。按钮悬停高亮、按下有轻微按压反馈；悬停可看短说明，持续运行时运行图标变为跳动短柱和环形流光，暂停、复位或失效后停止；系统“减少动态效果”保留静态运行标记并关闭位移动画；元件库最小化/关闭按钮悬停变色，点击才执行。

右下角矩形气泡是暂时操作反馈；详细故障仍在“工具 → 诊断与操作记录”，不会因气泡消失而清除。

在画布直接点击阀位控制，双击节流阀可设置当前运行开口。双击管道显示压力与流量，点击空白收起；手动路径编辑模式保留双击线段加锚点。

运行、暂停与新连线

点击油口选择起点，再点击目标油口连接；也可按住油口片刻，拖到目标油口后松开。选中起点显示橙色脉冲环，吸附到的目标显示绿色环；完成或取消后清除，减少动态效果时保留静态高亮。油口过近时请放大后选择。Esc、移出画布或窗口失焦可取消拖线，工程保持。连接选择时可以滚轮缩放查看。

▶运行先按当前参数初始化，Ⅱ暂停保留结果；▷单步推进一个显示步，↺复位回设计初态。没有新增运行快捷键。未知或失效结果不会当作零；运行状态在属性结果区查看，绘图来源可在“帮助 → 工程信息”查看。

右下角显示当前仿真时间及实际步长。点步长查看自动/手动选择和依据；改变选择只设置下次初始化，点击“按所选步长重新初始化”才明确应用。历史曲线步长与当前运行分开显示。

“新连线：理想/物理管”仅决定以后创建的连线。理想连接等压且忽略管损；物理管需填写实际管长、直径等参数，先预览再确认。画线距离不代替真实管长。默认理想，可在设置中恢复默认，不更改旧管路。

从“编辑 → 连接”开始，依次选两个油口或显式节点；“编辑 → 取消连接”或Esc结束手势。画面交叉不代表连通。选择对象、拖动、查看和保存不改变有效物理结果；真实参数或拓扑变化后需重新初始化。

图中名称显示选项在PDF/SVG原理图导出窗口，右侧不再放置。

文件与导出

新建时填写工程名，生成同名工程目录；重名自动递增编号，保留已有文件。打开目录中的“工程.hydproj”。“工程目录说明.md”解释每个目录的用途；整个目录可以一起移动。

旧hydx/JSON导入后另存文件夹副本，保留原件。保存保留旧批次；另存只带当前保存快照，不复制旧结果和诊断。教学端继续使用原单文件，不打开进阶文件夹工程。

文件夹工程的PDF、SVG、CSV、Word及曲线数据按用途归档到exports，每次单独成批，重名递增编号；也可另选导出位置。归档不保存当前编辑，结果身份见各批index.json。

帮助菜单可归档本机应用诊断：当前及最近20次界面诊断、当前运行诊断，最多200项，省略自由文本、路径、用户标签及鉴权信息，不上传。保存在diagnostics；历史保存、导出与诊断批次不自动清理。

“文件”菜单集中新建、打开、保存、另存为和导出。Ctrl+S保存，Ctrl+Shift+S另存为。取消或失败保留当前编辑；保存期间又编辑时，只确认已捕获的版本，当前新编辑仍显示未保存。

进阶端使用v3工程；旧文件通过迁移副本打开并另存，保留原模型，不承诺可由原生网络求解。教学端不能打开v3自由网络工程。

CSV是表格数据，SVG是矢量图；曲线、计算过程和导出使用明确的当前/历史来源，未知值留空。导出有现有容量保护，超过容量会明确失败，不静默减少精度或丢样。

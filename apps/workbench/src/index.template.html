先完成一次教学演示

  1. 「加载示例」选择油缸或马达。点击阀体只选中，上方「控制」条切换左位 P→A / 右位 P→B；A/B交叉可能反转动作。
  2. 暂停时换位得到静态预览，不推进时间和轨迹。点「单步」前进0.01s；运行速度只改步数。
  3. 选中元件 → 属性 → 修改负载或溢流压力 → 应用修改。未应用输入不写入恢复副本。物理修改和撤销/重做暂停并复位，旧记录标为历史。名称和布局保留曲线。
  4. 「结果」看数值及未知原因，「曲线」选择当前或修改前历史轨迹（虚线），「诊断」定位错误。小屏用完整回路浏览、100%及横纵滚动精确操作。
  5. 保存为本机 .hydx，取消或失败保留修改；旧JSON迁移需另存且保留原件。文件菜单查看完整路径、最近工程和恢复副本。
  6. 「记录 / 导出」明确选择静态预览、当前轨迹、历史或纯图，导出SVG / CSV。当前轨迹须有成功计算步，未知量不会导成假零。

模型与单位

准静态计算 + 动作演示。单油箱、单泵、溢流阀、O/M换向阀、单油缸或马达的指定七连接基础回路；管线相交不表示相通。忽略惯性和压缩性，未单独建模泄漏、气蚀、压力冲击、负负载下滑；中位保持力/转矩与封闭腔压力未求解。

压力MPa、流量L/min、缸位mm、缸速mm/s、管长m、管流速m/s；单位来自参数注册表。真实零显示0，未知显示「—」及原因。过载和终点为基础静态工况。

30元件/60连接仅是绘图容量，不表示任意回路可算。数值模型边界：缸杆径极接近浮点分辨率时可能明确求解失败，合法文件不保证全数值域可计算。

扩展元件库、手动管线、自定义阀仍按E系列延期；当前没有对应入口。G15-08真实30分钟长稳及目标机验收尚待补证。

系统字体与本地矢量离线运行；摩擦系数沿用基于开源库的克拉蒙德算法（许可和版本见安装目录技术文件）。不是工程安全校核或真实瞬态仿真。
